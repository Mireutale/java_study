## 1. Hello World

### 개발 환경 설정

- IDE - 인텔리제이 vs 이클립스  
  - 과거에는 이 클립스를 많이 사용했지만 최근에는 빠른 속도와 사용의 편의성 때문에 인텔리제이를 주로 사용한다.  

---

- OS - Mac vs 윈도우  
  - 자바로 개발하는 대부분의 메이저 회사들은 Mac 사용  
  - 윈도우를 사용해도 무방함

### 주석 comment

- 한줄 주석 "//"
- 여러줄 주석 "/* */"

---

### JAVA

- 자바 표준 스펙
  - 자바의 설계도, 문서

---

- 자바 구현
  - 여러 종류의 JAVA가 존재(Oracle, Amazon Corretto 등..)

---

- 특징
  - 모든 자바 구현은 표준 스펙에 맞도록 개발 -> 다른 자바로 변경해도 대부분 문제 없이 동작

---

- 컴파일 과정
  - .java -> .class -> JVM(자바 가상 머신)
  - 바이트 코드로 변환하고, 자바 가상 머신에서 실행
  - 인텔리제이 -> 자바를 OS에 직접 설치하지 않음, out 폴더에서 자동으로 class형태로 변경 및 JVM에서 실행

---

- 자바 프로그램
  - 자바는 자바가 설치된 모든 OS에서 실행할 수 있다.
  - 특정 OS에 맞추어 개발하지 않아도 됨. 
    - 각 OS에 맞는 자바를 설치해서 수행하면 된다.

## 2. 변수

### 변수 선언, 타입, 초기화

- 변수 선언
  - C언어와 동일

---

- 타입
  - int 정수
  - double 실수
  - boolean 
  - char 문자 1개
  - String 문자열
    - 자바는 대문자를 인식 -> 반드시 String에서 시작을 대문자 S 사용

---

- 리터럴
  - 개발자가 직접 입력한 고정된 값

---

- 숫자 타입
  - 정수
    - byte 8bit
    - short 16bit
    - int 32bit
    - long 64bit
  - 실수
    - double 8바이트
    - float 4바이트

---

### 변수 명명 규칙
  - 숫자로 시작 x
  - 공백 x
  - 예약어 x
  - 영문자, 숫자, 달러, 밑줄만 사용 가능
  - 관례적으로 카멜 케이스(camel case) 사용
    - 클래스는 대문자, 나머지는 소문자
    - 예외, 상수 -> 모두 대문자 및 언더바 / 패키지 -> 모두 소문자
